# Ocean Notes – Features

- Two-pane layout: notes list on the left, editor on the right
- Create, view, edit, and delete notes
- Local Storage persistence (loads on refresh)
- Search/filter by title
- Responsive design: collapsible list on small screens
- Modern UI using the Ocean Professional theme (blue & amber accents, gradients, rounded corners, subtle shadows)
- Accessible inputs and focus states

## Keyboard tips

- Use Tab/Shift+Tab to move between title and content.
- Type in the search box to filter notes by title.

No backend calls are made; data is stored in the browser only.
